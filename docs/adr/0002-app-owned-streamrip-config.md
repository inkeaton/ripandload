# The app owns a separate Streamrip config

The app never edits the user's personal streamrip `config.toml`. It keeps its own Streamrip config file, seeded once from the user's file if one exists (on Linux; on Windows rip creates a default), and passes it to every run with `rip --config-path`. This means the app's Settings can never break a hand-tuned personal setup, and the app always knows exactly which file it controls. On Windows the file lives next to Settings in `%APPDATA%`, rather than inside WSL, and rip reads it through `/mnt/c/…`. Settings already hold the same Credentials there, and the app can keep editing the file with ordinary file access. The file is edited with `toml_edit` so comments and keys the app doesn't manage are preserved.
